# Launcher Le Eaglercraft

A simple web-based launcher for multiple versions of Eaglercraft and classic Minecraft builds.

Part of the **Template Network**.

---

## Features

- Launch multiple Eaglercraft versions
- Embedded iframe game loader
- Fullscreen support
- Progressive Web App (PWA) support
- Service worker support
- Simple lightweight interface

---

## Included Versions

- Minecraft 1.12.2
- EaglercraftX 1.8.8
- Beta 1.7.3
- Beta 1.3_01
- Alpha 1.2.6
- Minecraft Indev
- C0.30

---

## Usage

1. Open `index.html` in your browser.
2. Click a version button to launch the game.
3. Use the fullscreen button for immersive gameplay.
